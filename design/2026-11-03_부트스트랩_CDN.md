# 2026-11-03 작업 설계 — 화면에 부트스트랩(CDN)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 기능(가입·로그인·글 CRUD·파일 업로드·내려받기)이 다 있으니 화면 모양을 부트스트랩으로 맞춘다. 라이브러리는 **CDN으로 포함**(받은 의견) |
| 범위 | 화면 9개 + 공통 메뉴 조각: `index`, `board/`(list·detail·write·edit·fetch), `member/`(join·login), `error/403`, `common/header` |
| 안 하는 것 | 직접 디자인·색 정하기, 자체 CSS 파일(필요하면 몇 줄만), 기능 변경(화면 모양만) |

## 2. 라이브러리를 들여오는 방법 비교 — 왜 CDN인가

| 방법 | 어떻게 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| **CDN** | 화면에 공용 서버 주소 한 줄(`<link href="https://cdn.jsdelivr.net/…">`) | 설치·빌드 없음, 바로 씀, 많은 사이트가 같은 파일을 써서 브라우저에 이미 있을 수 있음 | 인터넷이 있어야 함, 그 서버 사정에 기댐(그래서 버전 고정 + 무결성 검사 `integrity`) |
| npm | `npm install bootstrap` → `node_modules/`에서 `static/`으로 옮기거나 빌드 | 버전 관리가 `package.json`에, 필요한 부분만 골라 빌드 가능 | Node·빌드 단계가 필요, 우리 프로젝트(빌드 없는 템플릿)엔 연결 작업이 큼 |
| 직접 내려받기 | 파일을 `static/`에 넣고 `th:href="@{/css/…}"` | 인터넷 없어도 됨 | 버전 올릴 때 파일을 직접 갈아 끼움 |
| WebJars | 부트스트랩을 `pom.xml` 의존성으로 | Maven 한곳에서 관리 | 자바 쪽 도구로 JS를 관리하는 방식(참고만) |

→ 받은 의견대로 **CDN**. 우리 화면은 서버가 그리는 템플릿이고 빌드 단계가 없어서 가장 가볍다.

## 3. 넣는 위치 — 머리 조각 하나

- 부트스트랩 CSS는 각 화면 `<head>`에, JS(메뉴 접기 등)는 `<body>` 끝 또는 `<head>`에 `defer`로.
- 화면 9개에 같은 줄을 반복하면 버전을 올릴 때 9곳을 고침 → **`common/head.html`에 머리 조각**(`th:fragment`)을 만들어 CSS·JS 줄을 한곳에 두고, 각 화면 `<head>`에서 `th:replace`로 가져온다(10/30 메뉴 조각과 같은 방식).
- 버전은 주소에 고정(예: `bootstrap@5.3.x`). `integrity` 값은 **부트스트랩 공식 문서의 CDN 안내에서 그대로 복사**(직접 만들거나 추측하지 않음).

## 4. 화면별로 바뀌는 것(모양만)

| 화면 | 부트스트랩 요소 |
|---|---|
| 공통 | 본문을 `container`로 감쌈, 안내 줄(`errorMessage`)은 `alert alert-warning` |
| 메뉴 조각 | `navbar` |
| 목록 | `table table-hover`(열은 지금 그대로 제목·내용 — 모양만), 글쓰기는 메뉴에 있음 |
| 상세 | 제목·내용·첨부 목록 정리, 수정·삭제·목록 버튼(`btn`) |
| 글쓰기·수정·가입·로그인 | 칸마다 `mb-3` 묶음, 입력 칸 `form-control`, 이름표 `form-label`, 버튼 `btn btn-primary`, 가입·로그인 폼은 절반 폭(`col-md-6`), 가입 비밀번호 칸 아래 규칙 안내(`form-text`) |
| 403 화면 | `alert` + 홈 버튼 |

## 5. 진행 방식

- 받은 요구사항: **"경로(로직)는 본인, CSS는 Claude"**. → **본인**: CDN 연결·머리 조각·각 화면 `th:replace`(처음 다루는 방식이라 예시 먼저), JS가 화면을 그리는 곳의 클래스(`board/fetch.html` 목록). **Claude**: 템플릿 태그에 클래스 붙이기(모양) 일괄 → 본인 확인.
- 화면 하나 바꿀 때마다 구동 확인(10/14 피드백).

## 6. 확인 방법

| 해 볼 것 | 성공 기준 |
|---|---|
| 아무 화면 열기 → 개발자 도구 Network | `bootstrap.min.css`가 CDN 주소에서 200 |
| 화면 9개 둘러보기 | 모양만 바뀌고 기능(저장·수정·삭제·가입·로그인·로그아웃·내려받기·403 안내)은 그대로 |
| (CDN의 아쉬운 점 직접 보기) 개발자 도구에서 네트워크 끊기(Offline) 후 새로고침 | 부트스트랩이 안 붙어 모양이 예전으로 — CDN은 인터넷에 기댐 |
