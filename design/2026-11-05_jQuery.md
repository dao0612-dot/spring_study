# 2026-11-05 작업 설계 — jQuery 한 번 써 보기

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 받은 의견(11/04 저녁): "jQuery 한 번 써 봐라". 회사 코드(탭탭 화면 파일 다수)에 jQuery가 많아 **읽을 줄 아는 것**이 목표 |
| 대상 | **fetch 목록 화면**(`board/fetch.html` → 이름을 `board/jquery.html`로) — 순수 JS로 짠 "API 부르기 → 목록 그리기"를 jQuery로. 서버 요청(`$.ajax`)·요소 만들기·붙이기가 한 화면에 다 있고, 읽기(GET)라 CSRF가 없어 jQuery 자체에 집중 |
| 안 하는 것 | 다른 화면 바꾸기(글쓰기·삭제는 순수 JS 그대로), 부트스트랩과 묶기(부트스트랩 5는 jQuery 불필요) |

## 2. 들여오기

- **CDN**(부트스트랩과 같은 방식): jQuery 공식 다운로드 페이지의 CDN 줄(`code.jquery.com/jquery-3.x.x.min.js`, `integrity` 포함)을 **본인이 복사**.
- 위치: 이 화면 `<body>` 끝의 우리 `<script>` **바로 앞**(우리 코드가 `$`를 쓰기 전에 jQuery가 먼저 읽혀야 함). 이 화면만 쓰므로 머리 조각(`common/head.html`)엔 넣지 않음.

## 3. 바뀌는 코드(같은 일을 두 문법으로)

| 하는 일 | 지금(순수 JS) | jQuery |
|---|---|---|
| 화면이 준비되면 실행 | `loadBoards();`(맨 아래에서 바로 부름) | `$(function () { … });` |
| 서버 요청 | `await fetch('/api/board/list')` → `await res.json()` | `$.ajax({ url: '/api/board/list', method: 'GET', dataType: 'json' })` → `.done(function (body) { … })` |
| 실패 | (없음) | `.fail(function () { … })` |
| 반복 | `body.data.forEach(board => …)` | `$.each(body.data, function (i, board) { … })` — 칸 순서가 **(순번, 원소)** |
| 요소 만들기 | `document.createElement('li')` | `$('<li>')` |
| 클래스·속성·글자 | `li.className = …`, `a.href = …`, `a.textContent = …` | `.addClass(…)`, `.attr('href', …)`, `.text(…)` |
| 붙이기 | `li.appendChild(a)`, `getElementById('board-list').appendChild(li)` | `.append($a)`, `.appendTo('#board-list')` |

- `$('#board-list')` = `document.getElementById('board-list')`처럼 **CSS 선택자로 찾기**(`#` = id, `.` = class).
- `.text()`는 `textContent`처럼 글자 그대로 넣음(제목에 `<script>`가 있어도 실행 안 됨). `.html()`을 쓰면 태그로 해석되니 쓰지 않음.

## 4. 확인 방법

| 해 볼 것 | 성공 기준 |
|---|---|
| `/board/jquery` 열기 | 지금처럼 글 목록(링크)이 뜸, 클릭하면 상세 |
| Network | jQuery 파일이 CDN에서 200, `/api/board/list` 요청 하나 |
| Console | 오류 없음(`$ is not defined`면 jQuery 줄 위치·주소 문제) |
| 서버(EC2)에 새 jar로 다시 배포 | 서버에서도 같게 — 갱신 연습(멈춤 → jar 바꿈 → 켬) |
