## 기능 정의서

### 회원
- 기본 CRUD: 회원가입, 로그인, 회원정보 수정, 회원탈퇴
- 부가 기능: 내 정보 자세히 보기(마이 페이지)

### 게시판
- 기본 CRUD: 게시글 작성, 게시글 목록 읽기, 게시글 자세히 보기, 게시글 수정, 게시글 삭제
- 부가 기능: 게시글에 파일 업로드


## 기능 세부 내역

### 회원
- 회원가입은 이름, 아이디, 비밀번호로 가입.
- 마이 페이지에선 내 정보와 함께 내가 쓴 글을 확인할 수 있어야 한다.

### 게시판
- 게시글은 제목과 내용으로 구성
- 파일 업로드는 한번에 하나만

## URL 정의서
- 각각 템플릿, 라우트 | 메서드 방식 및 설명

### 메인
- 메인 화면: index.html, "/"

### 회원
- 회원가입: join.html, "/member/join" | GET 회원가입 화면, POST 회원가입 프로세스 (DB 레코드 신규생성)
- 로그인: login.html, "/member/login" | POST 로그인 프로세스
- 로그아웃: 없음, "/member/logout" | GET 로그아웃 (세션 지우기)
- 마이페이지: mypage, "/member/mypage" | GET 마이페이지
- 회원정보 수정: member_edit, "/member/edit" | GET 수정 화면, POST 수정 프로세스 (DB 레코드 수정)
- 회원탈퇴: 없음, "/member/delete" | POST 회원탈퇴 프로세스 (DB 레코드 수정/의미적 삭제처리)


### 게시판
- 게시글 등록: board_post, "/board/post" | GET 게시글 작성 화면, POST 게시글 저장 프로세스 (DB 레코드 신규생성)
- 게시글 목록 읽기: board_list, "/board/list" | GET 게시글 전체 목록
- 게시글 자세히 보기: board_view, "/board/view/<index>" | GET 게시글 자세히 보기
- 게시글 수정: board_edit, "/board/edit/<index>" | GET 게시글 수정 화면, POST 게시글 수정 로직 (DB 레코드 수정)
- 게시글 삭제: board_delete, "/board/delete/<index>" | POST 게시글 숨기기 로직 (DB 레코드 수정/의미적 삭제처리)

## h2 DB 쿼리

### 테이블(member, board)

create table member(
id int AUTO_INCREMENT PRIMARY KEY,
name varchar(50) not null,
user_id varchar(50) not null,
password varchar(250),
role enum('user','admin') not null default 'user',
active bool not null default 1
);


create table board(
id int AUTO_INCREMENT PRIMARY KEY,
title varchar(255),
member_id int,
content varchar(3000),
del_yn enum('Y','N') not null default 'N',
created_at timestamp default current_timestamp,
CONSTRAINT member_fk FOREIGN key(member_id) REFERENCES member(id)
);
